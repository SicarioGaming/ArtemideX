The first release of Voidlink!

Voidlink brings the best features of the Android Moonlight clients into one app: Moonlight X's fast video, the touchscreen tools from Artemide and Artemis, and favourites from Moonlight V+, Moonlit Artemis and Moonlight X Turnip, with a new space-themed look. It installs next to any Moonlight you already have. The [README](https://github.com/SicarioGaming/Voidlink#readme) has the full feature list, a getting-started guide and credits for everything I borrowed.

### What's in it
- **A new look:** the screens take their colour from the game you pick, over a starfield. Apps without cover art, like Desktop and Steam Big Picture, get their own icons.
- **Touchscreen tools:** the floating menu button, the Shortcuts page, pan/zoom, touch modes, the full keyboard, clipboard sharing, PC commands and Virtual Display.
- **Smoother, faster video:** Warp Drive, Fast V-Sync, LFR, async decoding, and a custom Turnip driver for PyroWave.
- **Extras:** monitor switching, pinch to zoom anytime, changing the bitrate mid-stream, audio haptics and shortcuts imported from a file.

### Install
Download **Voidlink-0.1.0.apk** below on your Android device and open it. Android will ask you to allow installing apps from your browser or file manager. It needs Android 5.0 or newer; PyroWave and the Turnip driver need a 64-bit ARM device. Some features need an Apollo-based host like Vibepollo.

This is the first release, so if something misbehaves, please [open an issue](https://github.com/SicarioGaming/Voidlink/issues). I made Voidlink with AI: I decided what it should do and how it should look, and Claude Code wrote the code.

### Check your download
- APK SHA-256: `APK_SHA256`
- Signing certificate SHA-256: `CERT_SHA256` (every Voidlink release will use this same certificate)
