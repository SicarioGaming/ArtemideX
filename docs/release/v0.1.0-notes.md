The first release of ArtemideX!

I kept switching between Moonlight X (for its video) and Artemide (for its touchscreen tools), so I combined them into one app, added a few favourite features from other Moonlight versions, and gave it a new look. It installs next to any Moonlight you already have. The [README](https://github.com/SicarioGaming/ArtemideX#readme) has the full feature list, a getting-started guide and credits for everything I borrowed.

### What's in it
- **A new look:** the game screen, settings and in-stream menu take their colour from the game you pick. Apps without cover art, like Desktop and Steam Big Picture, get their own icons.
- **From Artemide and Artemis:** the floating menu button, the Shortcuts page, pan/zoom, touch modes, the full keyboard, clipboard sharing, PC commands, Virtual Display, Warp Drive, Fast V-Sync, LFR, async decoding, and shortcuts imported from a file.
- **From other versions:** the custom Turnip driver for PyroWave (Moonlight X Turnip), monitor switching and pinch to zoom anytime (Moonlit Artemis), and changing the bitrate mid-stream and audio haptics (Moonlight V+).

### Install
Download **ArtemideX-0.1.0.apk** below on your Android device and open it. Android will ask you to allow installing apps from your browser or file manager. It needs Android 5.0 or newer; PyroWave and the Turnip driver need a 64-bit ARM device. Some features need an Apollo-based host like Vibepollo.

### Heads up
This is a first release. Everything has passed tests on my own tablet (Snapdragon 8 Elite, Android 16), but it hasn't had much real-world streaming yet, so please [open an issue](https://github.com/SicarioGaming/ArtemideX/issues) if something misbehaves. I made ArtemideX with AI: I decided what it should do and how it should look, and Claude Code wrote the code.
