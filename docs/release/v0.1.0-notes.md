**ArtemideX 0.1.0: first release (early)**

ArtemideX is a Moonlight client for Android built on Moonlight X, with Artemide's (and Artemis's)
options and in-stream menu, a few features from other forks, and the new Cover Glow look. It
installs beside Moonlight, Moonlight X and Artemide. See the [README](https://github.com/SicarioGaming/ArtemideX#readme) for the full
feature list and where each feature came from.

> [!WARNING]
> **Vibecoded with AI.** The ArtemideX code was written by Claude (Anthropic) in Claude Code,
> directed by a beginner, with [REA](https://github.com/morluto/rea) (by morluto) used alongside.
> It has on-device tests but no line-by-line review by an experienced developer. Treat it as
> experimental.

### Highlights
- **Cover Glow:** the game screen, settings and in-stream menu take their colour from the game's
  cover; plain-language settings with a "What you'll feel" panel
- **From Artemide / Artemis:** floating menu button, Shortcuts page, pan/zoom, touch modes, full
  keyboard, clipboard and PC commands, Virtual Display, Warp Drive, Fast V-Sync, LFR, async decode,
  custom shortcuts imported from a file
- **From other forks:** custom Turnip driver for PyroWave (Moonlight X Turnip), monitor switcher
  and pinch to zoom anytime (idea from Moonlit Artemis), bitrate mid-stream and audio haptics
  (idea from Moonlight V+)

### Status
Every feature has on-device tests (Snapdragon 8 Elite tablet, Android 16), but most haven't been
used in a real stream yet. Please open an issue with what you find.

### Install
Download **ArtemideX-0.1.0.apk** below on your Android device and open it (allow "Install unknown
apps" for your browser or file manager). Android 5.0+. PyroWave and the custom Turnip driver
need a 64-bit ARM device. Several features need an Apollo-based host such as Vibepollo.
